# دروسي التفاعلية — Android Native

نسخة Android Native مستقلة لتطبيق تعلم الإنجليزية B1.

## الحالة الحالية
- Kotlin + Jetpack Compose.
- الدروس المرفقة داخل APK من مجلد `assets/lessons` مع اكتشاف الأقسام الرقمية تلقائيًا.
- قائمة الدروس مرتبة برقم الدرس.
- مشغل درس مع السابق/التالي وحفظ موضع الطالب.
- حفظ إجابات التمارين وحالتها محليًا.
- حالات التقييم منفصلة: `Correct` / `Incorrect` / `Unsupported`.
- معلم ذكي سياقي داخل القسم الحالي.
- BYOK: المفتاح لا يوضع في المصدر، ويُخزّن محليًا باستخدام Android Keystore + AES/GCM.
- دعم Gemini وOpenAI Chat Completions.
- معالجة أولية لأخطاء الشبكة وعدم وجود المفتاح.
- GitHub Actions لبناء Debug APK.

## ملاحظة مهمة
البيئة الحالية لا تحتوي Android SDK/Gradle ولا اتصالًا خارجيًا، لذلك لم يتم الادعاء بأن APK تم بناؤه هنا. ملف workflow يبني المشروع على GitHub.

## بناء APK على GitHub
1. أنشئ مستودع GitHub جديدًا.
2. ارفع محتويات هذا المجلد إلى الفرع `main`.
3. افتح تبويب Actions وشغّل `Build APK`.
4. بعد اكتمال البناء، افتح Run الناجح ثم Artifact باسم `drusi-debug-apk`.

## ما يلي قبل Release النهائي
- تحويل أنماط الاختيار والفراغ والترتيب والتصحيح إلى مكونات تفاعلية أصلية مرتبطة مباشرة ببنية التمرين.
- تقييم موحّد مع feedback ودرجة المحاولة.
- استيراد الدروس من ملفات خارج APK عبر Storage Access Framework.
- Backup / Restore.
- اختبارات Unit/UI/Instrumentation على الحالات الحرجة.
- إحصائيات وتقدم مفصل.
- TTS والتسجيل الصوتي.
- توقيع Release AAB/APK بمفتاح نشر المستخدم.
